💡 Comment ça fonctionne ?

  1. Depuis un PDF ou une photo : glissez le fichier ou cliquez pour le sélectionner.
  2. Depuis une capture d'écran : faites votre capture (ex: Windows + Shift + S), venez sur la page et faites Ctrl + V !
  3. L'outil extrait le texte, élimine les mots coupés (ex: trans- formation ➔ transformation), rétablit les accents français et structure les paragraphes.
  4. Cliquez sur « 📋 Copier dans Word » : votre texte est prêt !
